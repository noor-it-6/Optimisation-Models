Problem type: binary selection (knapsack) models

A binary selection model makes yes-or-no decisions: fund a project or not, open a site or not. Each choice uses some of a limited resource and adds some value. The model picks the combination with the most value that fits. With a single budget it is called a knapsack problem: pack the most valuable items into a bag of fixed size.

How to recognise one

  • Each option is all or nothing: there is no half a project.
  • Options use a limited resource, usually money, and add a known value such as NPV.
  • There may be rules linking options: one or the other, one only if another, at most so many.
  • The decisions are 0/1 variables, one per option.

The key modelling idea: 0/1 variables do logic

Because each \(X_i\) is 0 or 1, sums and inequalities between them express rules. \(X_3 + X_4 \le 1\) means "not both". \(X_1 \le X_7\) means "1 only if 7". Stage 08 shows how.

Check yourself: is it a binary selection model?

A charity chooses which of 12 grant applications to fund from a £500,000 pot, to help the most people.

Yes. Each grant is funded fully or not at all, and they share one budget: a knapsack.

Barney-Jones decides how many dollars to put into each of five investments.

No. Amounts can take any value, so the variables are continuous. It is a linear multi-period model (14.6).

A care board decides where to open clinics so as many people as possible live near one, within a budget.

Yes. Each site is opened or not, with a budget: a binary model. It also needs coverage variables, as in maximal covering (14.10).

Model formulation

The model formulation uses the notation in the table: one budget constraint and a binary variable for each investment.

Table 1. Model notation table.
NotationDescription
Sets\(I\)Set of potential investments, indexed by \(i\), \(I = \{1,\dots,7\}\)
Parameters\(C_i\)Cash required by investment \(i \in I\) ($ million)

The objective (1) maximises the total NPV of the investments chosen: because each \(X_i\) is 0 or 1, it adds the NPV of exactly those investments undertaken. Constraint (2) ensures that the total cash required by the chosen investments does not exceed the $15 million available. Constraints (3) make every decision a yes or no, so no investment can be partly funded.

Integer optimality tolerance

Solver stops an integer search once it is within the Integer Optimality percentage of the best possible value (1% by default in some versions). Set it to 0% to be sure the answer is truly optimal.

05

The optimal portfolio adds $16.7 million of NPV

Investments 3, 5 and 6 use $14.9m of the $15m. Two other portfolios tie exactly.

Why Solver may show a different answer

All three portfolios add $16.7m. Which one Solver reports depends on its search order. Each is correct; a manager can choose between them on other grounds, such as risk or strategy.

What if partial investments were allowed?

Without (3), the LP funds 44% of investment 1 and reaches $17.06m. It is an upper bound: no whole-project portfolio can beat it. The gap of $0.36m is the cost of indivisibility.

Why no Sensitivity Report?

Shadow prices measure the value of a tiny change in a resource. With whole projects, a little more budget is worth nothing until it is enough to afford a different combination, and then NPV jumps. The line is a staircase, not a slope, so there is no single "value per extra $1" to report. Re-solving at each budget is the only reliable way.

Why does this answer differ from stage 05?

The single-budget portfolio 3, 5, 6 needs only $6.4m in year 1 but $8.5m in year 2, more than the $6m available that year. Investments 1, 2 and 4 are front-loaded: they use all $9m of year 1 and just $4.3m of year 2. Timing, not just total cost, now decides the portfolio.

08

Logical constraints between investments

Real projects interact. Because each \(X_i\) is 0 or 1, rules between them can be written as linear constraints. This stage uses a $19m budget, where one portfolio is clearly best; at $15m three portfolios tie, so a rule often just moves Solver to another equally good one.

Which way round? Checking an if-then rule

"Investment 1 can only go ahead if investment 7 does." Every combination of \(X_1\) and \(X_7\) is listed. The rule forbids exactly one of them. Which inequality forbids the same one?
